# Personal Agent

[Documentation index](../README.md)

> Target architecture derived from Project PT specification v3.0, November 2026. These are planned capabilities unless explicitly stated otherwise.

Purpose: Organise daily life and operate approved desktop functions.

Capabilities:

- Read and manage calendar events with authorization.
- Create recurring and one-time reminders.
- Open allowed Windows applications and folders.
- Maintain tasks, deadlines, and daily summaries.
- Search approved local notes and files.
- Review recent activity and pending obligations.
- Support screen interpretation when explicitly enabled.

The Personal Agent must distinguish between reading information, proposing changes, and committing changes.

A calendar event creation may require confirmation; silently overwriting an existing meeting should not be permitted.
